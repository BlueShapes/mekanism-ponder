## 字幕の是正と受け入れ

以前の実装はフォントで折り返した行を2～3行ずつ別ページへ送り、文の途中で切っていました。
現在は [字幕形式](caption-authoring.md) に従い、原文・各訳文で明示した完結した短文だけを切り替えます。
アラビア語の実描画幅による改行は一つの標準吹き出しの中だけで行い、ページ境界に戻しません。
長すぎる未知の文を実行時に切断・省略せず、制作時の実フォント検査で検出します。

旧分割器で9件の本番メソッドの回帰テストが失敗することを確認してから修正しました（REDコミット `a8e180e`）。
初回の実測で見つかった55単位の行数超過、95件のアラビア語の描画幅超過を是正し、再測定で残った6単位も短文化しました。
空白だけが次行に入らない場合に、すでに収まった単語まで送る問題も回帰テストで修正しました。
最終結果は全5,677単位で最大3行です。具体例と各言語レビューは [日英](caption-source-review.json)、
[アジア](caption-review-asia.json)、[西欧](caption-review-west.json)、[その他7言語](caption-review-east.json) に記録しています。

## 配置と限界

指定PrismLauncherインスタンス `1.21.1 mod creation test` の `minecraft/mods` に0.1.2の主配布JARを配置し、SHA-256を確認しました。
同じMOD IDで確認した旧ガイド0.1.1だけを除去しました。Mekanism・Ponder・Flywheelは既存の指定版を再利用し、他のMODと `.index` は変更していません。
配置先はMinecraft 1.21.1 / NeoForge 21.1.262です。実行状態とハッシュは [deployment.json](deployment.json) を参照してください。

GUI検査はPonder画面を指定サイズへ再初期化する方式で、デスクトップの物理ウィンドウはリサイズしていません。
W長押しの物理入力は合成せず、キー設定を保持し、同じネイティブファクトリー経路を確認しました。
ガイド未導入サーバーへの実接続、8解説MODの同時起動、配置先Prismインスタンス自体の起動、MODパック独自レシピ・設定は未検証です。
模型は実機械の処理シミュレーションではありません。別のMinecraft版・ローダーも対象外です。
