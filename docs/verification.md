# 0.1.5 アイテム入口の監査・検証

2026-10-23。Minecraft 1.21.1 / NeoForge / Java 21、Mekanism 10.7.19.85。

固定版のソース登録・動的登録ヘルパーから381実IDを独立に抽出し、固定JARの資源と照合しました。
状態専用モデル21件を別アイテムとして数えていません。最終クライアントの実レジストリとも381件すべて一致しました。
固定実装と生成された35レシピの根拠、全実IDの修正前後の入口は
[item-coverage-expectations.json](item-coverage-expectations.json) に記録しています。
自分の登録表だけを期待集合として使っていません。
本体の説明原本（IHasDescription、ModuleData、Upgradeの機能文）も独立した解説対象として照合しました。
対象版にはGuideME形式の本はなく、他MODのガイド構造や古いWikiの版を仮定していません。

| 入口 | 修正前 | 修正後 |

| 本ガイドのW対象 | 110 | 175 |
| 本ガイドの通常Shift対象 | 25 | 192 |

最後の36件は、本体が既に機能を説明するモジュール31件（通常説明＋Shiftで対応機器・競合）、
アップグレード4件（Shiftで個別の機能説明）、内部専用の `mekanism:bounding_block` 1件です。
内部ブロックはマルチブロックの占有位置を表すプロキシで、利用者向けの機械や独立した教材ではありません。
本体の一般ブロック説明の既定キーはShift＋N、詳細はShiftです。
本体の既存説明を保持し、その翻訳を本ガイドの全22言語対応として数えていません。

工場はFactoryTypeの9種類×4Tierの36種です。共通教材は濃縮工場を例に並列スロット・自動振り分け・
アップグレードを教えます。各工場にはさらに加工種別に合う教材、または圧縮・合成・製材の短文を関連付けました。
全工場が濃縮レシピを使うとは説明していません。

鉱石中間素材は7金属×5工程の35種です。対象は鉄・金・銅・オスミウム・錫・鉛・ウランで、
各変換を固定JARのレシピJSONとハッシュで確認しています。蛍石・宝石・非金属・汚れたネザライトの欠片を
同じ加工ラインへ一括登録していません。鉄を使う既存の模型・数値例は変更しておらず、実際の環境のレシピが優先です。

物流トランスポーターの経路色は設置後のブロックエンティティ状態です。この対象版に色ごとの別アイテムIDはありません。
Robitのスキン、保存設定・数式・周波数・装備モジュール・内容物はItemStackの情報として区別し、
空のスタックへ正規化しません。実クリエイティブキューブ2スタックと9スロットの数式をWの実ファクトリーと
`GuidePonderScreen.getSubject()` へ通し、個数・アイテム・全データ成分の保持を確認しました。
モジュールと充電情報を持つ実MekaSuitスタックは、ガイド説明と本体詳細を経由しても変化しませんでした。
色コンポーネントを架空の派生形として作る検査はしていません。
